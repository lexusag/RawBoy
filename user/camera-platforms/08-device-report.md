# Сессия 08: отчёт об устройстве

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 08 плана `user/camera-platforms/`: добавь в Настройки камеры кнопку, которая собирает текстовый отчёт об устройстве для составления нового профиля. Сначала прочитай `CLAUDE.md`, `user/camera-platforms/README.md`, `results/01.md`, `results/07.md`, этот файл.

## Зачем

Профиль для нового телефона сейчас можно составить только с adb в руках. С отчётом тестер присылает данные сам (решение 17).

## Что сделать

1. **Состав отчёта** — то, что разведка 01 собирала вручную:
   - описание телефона от детектора и выбранные слои профиля с итоговыми значениями;
   - по каждой камере и физическому объективу: уровень поддержки, возможности, размеры RAW и превью, тон-режимы, диапазоны ISO, выдержки и fps, шаг экспокоррекции, вспышка, OIS, карта виньетирования, причина отказа, если камера не подошла;
   - строка `GL_RENDERER`, список расширений, нужных камере, кодеры HEVC и H.264;
   - выученная калибровка по объективам;
   - результат пробы поверхности кодера, когда она появится (сессия 09 дописывает).
2. **Чего в отчёте нет:** серийных номеров, идентификаторов аккаунта, координат, имён файлов пользователя, снимков.
3. **Кнопка в Настройках:** собирает файл и открывает системное «Поделиться». Сам отчёт никуда не отправляется.
4. **Формат:** простой текст, читаемый человеком и удобный для сравнения двух телефонов.
5. **Документация:** `docs/camera.md`, `CHANGELOG.md`, `ui/Help.kt`.

## Тесты

- Сборщик отчёта из заготовленных данных даёт ожидаемый текст; пустые и отсутствующие поля не роняют сборку.
- На OnePlus 11 отчёт совпадает с ручными данными из `results/01.md`.
- Обе команды Gradle зелёные.
