# Сессия 07: автодетект, веха M2

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 07 плана `user/camera-platforms/`: приложение само определяет чип, производителя и модель телефона, собирает профиль из слоёв и показывает его в logcat и Настройках; в debug-сборке профиль можно выбрать вручную. Неизвестный телефон получает нейтральный профиль. Сначала прочитай `CLAUDE.md`, `user/camera-platforms/README.md`, `results/01.md`, `results/02.md`, `results/03.md`, `results/06.md`, этот файл.

## Зачем

Автодетект обязателен (решение 3). До этой сессии все телефоны жёстко получают профиль Tensor; после неё каждый получает свой.

## Что сделать

1. **`PlatformDetector`:**
   - чип: `Build.SOC_MANUFACTURER` и `SOC_MODEL` (API 31+); для API 29–30 — запасной признак по строкам, снятым в 01 (`Build.HARDWARE`, `Build.BOARD`);
   - производитель: `Build.MANUFACTURER`; модель: `Build.MODEL` и `Build.DEVICE`;
   - детектор только читает и возвращает описание телефона; значений он не выбирает;
   - нераспознанный чип — явное значение «неизвестен», а не догадка.
2. **`PlatformRegistry`:** по описанию собирает нейтральный → чип → производитель → модель (решение 4). Слои Qualcomm и OnePlus пока пустые: OnePlus 11 получает нейтральный профиль.
3. **Нейтральный профиль** по таблице 02 (решение 5).
4. **Снять временное правило** «всем Tensor».
5. **Диагностика** (решение 17):
   - строка в logcat при запуске: описание телефона, выбранные слои, итоговые значения;
   - строка в Настройках: слои профиля либо «нейтральный, телефон не проверялся»;
   - ручной выбор профиля в debug-сборке (Настройки или параметр запуска по adb).
6. **Калибровка под чужим профилем:** при ручном выборе выученные `previewScales3` и `flashGuides` пишутся отдельно и не портят калибровку автоматического профиля.
7. **Документация:** строка профиля — видимое изменение: `docs/camera.md`, `CHANGELOG.md`, `ui/Help.kt`.
8. **Веха M2:**
   - push, debug-APK;
   - чек-лист для Pixel 9 Pro: в Настройках и logcat профиль Tensor; повтор короткой проверки M1;
   - **сообщить владельцу репозитория:** с этой сборки телефоны без своего слоя получают нейтральный профиль; приложить сводку последствий из `results/02.md` и отдельно назвать Galaxy S25, Galaxy Tab S11 Ultra и Pixel на Snapdragon.

## Тесты

- Детектор на таблице строк: Tensor, Snapdragon, MediaTek, Exynos, пустые и незнакомые значения, API 29–30 без `SOC_*`.
- Реестр: Pixel 9 Pro получает профиль, равный прежним константам; неизвестный телефон — нейтральный; Samsung — базовый слой плюс `oem/samsung`.
- Обе команды Gradle зелёные.
- OnePlus 11: в Настройках и logcat нейтральный профиль; ручной выбор Tensor возвращает поведение сессии 06.

## Не делать

- Не наполнять слои Qualcomm и OnePlus.
- Не определять платформу по косвенным признакам (GPU, имена кодеров), если хватает `Build.*`; если не хватает — решение автора ветки.
