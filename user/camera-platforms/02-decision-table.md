# Сессия 02: таблица решений

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 02 плана `user/camera-platforms/`: по каждому месту перечня предложи, универсально оно, уходит в слой Tensor или получает нейтральное значение, и принеси таблицу автору ветки на утверждение. Сначала прочитай `user/camera-platforms/README.md`, `inventory.md`, `results/01.md`, этот файл. Код в этой сессии не пишется.

## Зачем

Неизвестный телефон получает нейтральный профиль без обходов Pixel (решение 5). Но часть «обходов» может оказаться основой работы камеры. Что есть что, решает таблица, которую утверждает автор ветки (решение 6).

## Что сделать

1. **Сверить перечень с кодом:** [inventory.md](inventory.md) — черновик. Строки, по которым принимается решение, сверяются с исходником.
2. **Заполнить колонку «Решение»** для каждой строки вида (a) и (b). Варианты:
   - **универсально** — остаётся в общем коде (механизм нужен всем либо уже проверяется по Camera2);
   - **Tensor** — значение или поведение уходит в слой Tensor; указать нейтральное значение и почему оно безопасно;
   - **проба** — выясняется на телефоне на ходу, профиль не нужен;
   - **не трогаем** — с причиной.
3. **К каждой строке — обоснование** в одну-две фразы и вердикт разведки 01 (держится ли допущение на OnePlus).
4. **Отдельно разобрать с автором ветки:**
   - Pixel на Snapdragon (до Pixel 6): слой Qualcomm или отдельный слой производителя Google;
   - Samsung: что остаётся в слое `oem/samsung`, раз S25 и Tab S11 Ultra окажутся на разных базовых слоях;
   - три копии числа 0.06 и константа `EXTRA_BLACK`, которую `CameraController` читает из `ShotSaver`;
   - числа без названного устройства (множители шума, пороги «мало света»): Tensor или универсальные.
5. **Сводка последствий:** что изменится для телефона без своего слоя по сравнению с сегодняшним поведением. Этот список пойдёт владельцу репозитория на вехе M2.

## Проверки

- В перечне не осталось строк (a)/(b) без решения.
- Автор ветки утвердил таблицу; спорные строки записаны решениями с номерами.
