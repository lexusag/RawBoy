## 2. Уже адаптивно (переносить не нужно, но знать стоит)

- **Объективы:** `Info` собирается из характеристик (CC:119–158, `infoFor` CC:344–402); причины отказа камеры пишутся в лог.
- **Частота кадров:** `previewFpsRange` (CC:172–175), `stillFpsRange` (CC:178–180).
- **Обрезка превью:** `previewCropX/Y`, когда нет превью с пропорциями raw (CC:196–209).
- **Тон превью:** путь выбирается из доступных режимов — preset, contrast curve, gamma (CC:370–375).
- **Физические объективы:** поток логической камеры, иначе открытие физического id (CC:426–460).
- **Чтение на ходу:** OIS, карта виньетирования, области AE/AF, шаг экспокоррекции (всё с проверкой наличия); boost из результата (CC:1783); профиль шума (CC:1344–1347); чёрный и белый для замера raw (CC:913–935).
- **Максимальное разрешение:** `maxResRaw` (CC:1862–1879), `isQuadBayer` (MR:402–451).
- **Видоискатель:** поворот и зеркало по матрице SurfaceTexture (VF:706–715); `GL_EXT_YUV_target` (VF:192).
- **Видео:** часы кадров (VR:87–96); источник звука CAMCORDER, затем MIC (VR:411–419).

## A. Кто кого создаёт (точки подвода профиля)

- Внедрения зависимостей нет: только `object` и ручное создание.
- `CameraActivity` получает `CameraViewModel` через `viewModels()`.
- `CameraViewModel` создаёт `CameraController(application)` (VM:97). Контроллер получает только `Context`; настройки приходят аргументами вызовов.
- Настройки: `CameraSettingsStore.load` (VM:105), неизменяемый `CameraSettings`.
- `ViewfinderRenderer` создаётся в `ui/Viewfinder.kt`:45–51. Данные о телефоне доходят до него только через `Frame` (гамма, усиление, поворот, зеркало, цвет). Матрица YUV и запасной путь EGL — внутри рендерера.
- `VideoRecorder.create(...)` — фабрика, вызывается из VM:322; она же строит `VideoSink`.
- `ShotSaver` — глобальный `object` (SS:123). Данные снимка приходят в `Shot` (SS:73–103). Константа `EXTRA_BLACK` читается из `CameraController` напрямую (CC:929).

## B. Ключи запросов Camera2

`setCommon` (CC:1590–1637) действует на все запросы.

- **Без проверки:** `CONTROL_MODE`, `CONTROL_AF_MODE`, `CONTROL_AE_MODE`, `FLASH_MODE`, `CONTROL_AWB_MODE`, `CONTROL_VIDEO_STABILIZATION_MODE = OFF`, `CONTROL_AE_LOCK`, `CONTROL_AE_EXPOSURE_COMPENSATION` (значение из характеристик).
- **С проверкой наличия:** диапазон fps, области AE/AF, OIS, три варианта тон-режима, распознавание лиц, карта виньетирования.
- **Снимок со вспышкой, без проверки:** `CONTROL_ENABLE_ZSL = false`, ручные выдержка, ISO и длительность кадра, boost 100, `FLASH_MODE_SINGLE`.
- **Отдельного запроса для видео нет:** видоискатель в видеорежиме использует запрос превью.
- **Не задаются вовсе:** `CONTROL_CAPTURE_INTENT`, `NOISE_REDUCTION_MODE`, `EDGE_MODE`, `COLOR_CORRECTION_*`: превью остаётся с настройками шаблона.

- `MAX_STILL_EXPOSURE_NS` не выводится из доступных диапазонов fps, хотя `stillFpsRange` выводится.

## E. Условия по версии Android и расширениям

- **API 31+:** режим максимального разрешения (CC:493, 1644, 1863; MR:77, 211, 894, 898).
- **API 33+:** `SurfaceTexture.dataSpace`, иначе 0 (VF:460).
- **API 34+:** высота над уровнем моря (VM:1338), тип foreground-сервиса (SS:643).
- **GL:** `GL_EXT_YUV_target` выбирает путь YUV или RGB (VF:192).
- **EGL:** `EGL_RECORDABLE_ANDROID` с запасным путём (VO:89).
