# Сессия 00: сборка и стенд

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 00 плана `user/camera-platforms/`: добейся сборки `:app-camera` из ветки на этой машине, поставь debug-сборку на OnePlus 11 рядом с версией из Google Play и сними базовые замеры. Сначала прочитай `CLAUDE.md`, `user/camera-platforms/README.md`, этот файл.

## Зачем

Сейчас ветку нельзя ни собрать, ни поставить на телефон. Без этого все следующие сессии слепые.

## Что сделать

1. **Инструменты сборки** (установка — с разрешения автора ветки, каждая команда называется заранее):
   - Adobe DNG SDK в `third_party/dng_sdk` по `third_party/README.md` (каталог в `.gitignore`);
   - NDK 27.2.12479018 и CMake 3.22.1 через `sdkmanager` (сейчас стоит только NDK 30);
   - проверить, что демон Gradle берёт JDK 21.
2. **Сборка:** `./gradlew :app-camera:assembleDebug`, затем `:app-camera:testDebugUnitTest :engine:testDebugUnitTest`. Первая нативная сборка качает LibRaw и jpegli — нужна сеть.
3. **Отдельное имя пакета для debug** (решение 16):
   - необязательный параметр Gradle (предложение: `rawboy.debugIdSuffix`), пустой по умолчанию;
   - при заданном значении debug-сборка `app-camera` получает `applicationIdSuffix`;
   - значение задаётся в `~/.gradle/gradle.properties` автора ветки, в репозиторий не попадает;
   - проверить, что без параметра итоговое имя пакета прежнее;
   - проверить манифест и код на жёстко заданное имя пакета: authorities провайдеров, собственные permissions, действия intent, строки вида `app.rawboy.camera` — иначе установка рядом не пройдёт или два приложения будут мешать друг другу.
4. **Установка на OnePlus 11:** debug-сборка рядом с версией из Play; версия из Play остаётся нетронутой. Выдать разрешения камеры и микрофона.
5. **Базовые замеры на debug-сборке ветки** (до любых правок кода камеры). Они, а не версия из Play, служат эталоном для всех следующих сессий: в Play другая версия кода и release-сборка.
   - сбой записи видео воспроизводится с теми же строками лога, что описаны в README («Известные технические факты»);
   - один снимок на каждом доступном объективе: сохранить пары «скриншот видоискателя / JPEG» и строки лога `shutter`, `still`, `calibrate`;
   - строка `lenses (facing N)`: какие объективы нашлись.
6. **Рецепт стенда** в отчёте: команды сборки, установки, запуска, записи лога в файл, съёма скриншота.

## Проверки

- Обе команды Gradle зелёные.
- На телефоне два пакета: из Play и debug.
- Без параметра Gradle `applicationId` debug-сборки равен `app.rawboy.camera`.

## Не делать

- Не править код камеры и движка: правка только в `app-camera/build.gradle.kts` (параметр суффикса).
- Не удалять версию из Play.
