# Сессия 06: вынос Tensor — движок, веха M1

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 06 плана `user/camera-platforms/`: дай движку параметры вместо зашитых допущений о Pixel (матрица YUV видоискателя, поверхность видеокодера), закрой вынос Tensor и подготовь веху M1 для владельца репозитория. Поведение не меняется ни на одном телефоне. Сначала прочитай `CLAUDE.md`, `user/camera-platforms/README.md`, `inventory.md` (разделы «Видео» и «Движок»), `results/03.md`–`results/05.md`, этот файл.

## Зачем

Часть специфики лежит в `:engine`, которым пользуются ещё Pro и Auto. Движок о платформах знать не должен (решение 10), поэтому он получает значения параметрами.

## Что сделать

1. **`ViewfinderRenderer`:** правило декодирования Y'CbCr приходит параметром; значение по умолчанию равно сегодняшнему.
2. **`EncoderSurface` / `VideoSink`:** порядок попыток создания поверхности приходит параметром; значение по умолчанию — сегодняшние два шага. Новых вариантов здесь нет, они появятся в 09.
3. **`VideoRecorder`:** числа и выбор кодера по таблице 02.
4. **`ui/Viewfinder.kt`:** создание `GLSurfaceView` получает параметры из профиля; сегодня это «конфиг не выбираем».
5. **Проверка границы:** в `engine/` нет импортов из `app.rawboy.camera.platform`; в общем коде камеры не осталось имён телефонов в исполняемом коде.
6. **Порты:** правки движка не меняют логику, общую с TS и Swift. Если какая-то правка её всё же меняет — остановиться и спросить автора ветки.
7. **Веха M1:**
   - push ветки, debug-APK;
   - чек-лист для Pixel 9 Pro: фото на каждом объективе и селфи, совпадение видоискателя со снимком, вспышка и фокус-вспышка, склейка 8 кадров, 50 МП, видео с образом и «плоское», длинная выдержка;
   - что прислать при расхождении: строки `shutter`, `still`, `calibrate` из logcat;
   - как ставить сборку: по договорённости с владельцем репозитория (README, «Вехи»). Если калибровка после установки пуста — сравнивать видоискатель со снимком только после 2–3 снимков на объектив, иначе расхождение ложное.

## Тесты

- Тест «Tensor равен прежним константам» покрывает все строки перечня с решением «Tensor».
- Обе команды Gradle зелёные.
- Эмулятор `Medium_Phone_API_37.0`: камера запускается (фронтальная камера эмулятора, см. `CLAUDE.md`).
- Дым на OnePlus 11: фото и видоискатель как в базовых замерах 00; видео по-прежнему не пишется (чинится в 09) — это ожидаемо.
