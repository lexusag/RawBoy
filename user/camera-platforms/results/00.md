## Параметр `rawboy.debugIdSuffix` (решение 16)

Параметр задаётся в `app-camera/build.gradle.kts`, в блоке `buildTypes.debug`. Если он задан и не пуст:
- debug-сборка получает `applicationIdSuffix` с этим значением;
- к имени версии добавляется `versionNameSuffix = "-debug"`.

Без параметра ничего не меняется.

Проверено по готовому APK через `apkanalyzer`:
- **без параметра:** `application-id` = `app.rawboy.camera`, версия `0.1.0`;
- **с `rawboy.debugIdSuffix=.dev`:** `app.rawboy.camera.dev`, версия `0.1.0-debug`.

Проверка на жёстко заданные имена пакета:
- в манифесте камеры нет provider, своих permission и своих intent-действий;
- в объединённом манифесте с суффиксом provider `androidx-startup` и `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` получают префикс `app.rawboy.camera.dev`;
- в коде камеры строк `"app.rawboy.camera"` нет. Строки `app.rawboy.action/extra.*` в `Edits.kt` относятся к Pro/Auto.

Общее у двух пакетов:
- **Папки вывода.** Обе версии пишут в `Pictures/RawBoy Camera` и `Movies/RawBoy Camera`: папки заданы в `Edition.FOLDER`, а не по имени пакета.
- **Системный выбор камеры.** Обе отвечают на `STILL_IMAGE_CAMERA`. Камеру по умолчанию на телефоне не трогали.
- **Ярлык.** Ярлык одинаковый, «RawBoy Camera». Различаются только версией в справке и Настройках: `0.1.0-debug`.

Значение `.dev` записано в `gradle.properties` в домашнем каталоге Gradle на машине автора ветки. В репозиторий оно не попадает.

## Рецепт стенда

Пути: `$SDK` — Android SDK, `<scratch>` — каталог scratchpad сессии.

```sh
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk        # лаунчер Gradle и sdkmanager; системная Java 27 не годится
# сборка (локально только arm64, флаг в командной строке, не в файлах)
./gradlew -Prawboy.abis=arm64-v8a :app-camera:assembleDebug
./gradlew -Prawboy.abis=arm64-v8a :app-camera:testDebugUnitTest :engine:testDebugUnitTest
# один adb на всё: в PATH есть второй adb (другой пакет), два сервера мешают друг другу
A=$SDK/platform-tools/adb
# на телефоне есть рабочий профиль (user 10): ставить и выдавать разрешения в user 0
$A install --user 0 -r app-camera/build/outputs/apk/debug/app-camera-debug.apk
$A shell pm grant --user 0 app.rawboy.camera.dev android.permission.CAMERA
$A shell pm grant --user 0 app.rawboy.camera.dev android.permission.RECORD_AUDIO
# лог потоком в файл ДО запуска, без фильтра по pid (ошибки кодера идут из процесса codec2)
$A logcat -c; $A logcat -v threadtime > <scratch>/logcat.txt &
# запуск: namespace остаётся app.rawboy.camera, поэтому активность пишется полностью
$A shell am start -W -n app.rawboy.camera.dev/app.rawboy.camera.CameraActivity
# скриншот
$A exec-out screencap -p > <scratch>/vf.png
# нажатие (input tap Compose иногда игнорирует)
$A shell input swipe X Y X Y 80
```

- **Координаты в альбомной ориентации** (экран 2412×1080):
  - спуск: 2140,718;
  - PHOTO / VIDEO: 2140,228 / 2140,324;
  - смена камеры: 2140,492;
  - объективы T / W: 1610,686 / 1610,830.
- **Видоискатель на скриншоте:** прямоугольник 300,206–1352,995.
- **Сравнение пар:** средние и корреляция центральной области (15–75 % по ширине, 20–80 % по высоте) после уменьшения до 240×180. Скрипт — ниже: scratchpad сессии временный, а снимки с телефона удалены.

```python
# pairs.py <vf.png> <shot.jpg> [mirror]: viewfinder screenshot (landscape, 2412x1080) vs JPEG
import sys, numpy as np
from PIL import Image
def lin(a): a = a / 255.0; return np.where(a <= 0.04045, a / 12.92, ((a + 0.055) / 1.055) ** 2.4)
def region(im):
    w, h = im.size
    return im.crop((int(w * .15), int(h * .2), int(w * .75), int(h * .8))).resize((240, 180), Image.BOX)
vf = Image.open(sys.argv[1]).convert('RGB').crop((300, 206, 1352, 995))   # viewfinder on screen
jp = Image.open(sys.argv[2]).convert('RGB')
a = np.asarray(region(vf), float); b = np.asarray(region(jp), float)
if len(sys.argv) > 3: b = b[:, ::-1]                                        # selfie is mirrored
Y = [0.2126, 0.7152, 0.0722]
dev = np.log2((lin(b) @ Y).mean() / (lin(a) @ Y).mean())
corr = np.corrcoef(a.mean(2).ravel(), b.mean(2).ravel())[0, 1]
print('vf', a.reshape(-1, 3).mean(0).round(1), 'jpg', b.reshape(-1, 3).mean(0).round(1), f'dEV {dev:+.2f} corr {corr:.2f}')
```
- **USB-переподключение.** При перекладывании телефона USB переподключился, и поток `logcat` оборвался молча: после любого движения кабеля проверять `adb devices` и перезапускать поток.
- **Удаление тестовых снимков.** Удалять через MediaStore, иначе в галерее остаются пустые записи:
  `content delete --uri content://media/external/images/media --where "_display_name='…'"`.

- после переключения на T (камера 0, потоки 1920×1440 превью и 4096×3072 RAW) кадры видоискателя не идут: строки `fps` в логе `RawBoyViewfinder` прекращаются;


**Снимки:**
- первый запуск, склейка включена: первое нажатие — `IOException: Burst: no frames` (`CameraController.burstDng`), следующие четыре — `IOException: Camera not ready`;

После переключения обратно на W камера снова работает. Разбирать — в сессии 01: вероятные подозреваемые — комбинация потоков, параметры сессии, а также запрос, который вызывает переконфигурацию.
